



# Bright Coffee Shop Dashboard

Live: https://brightbrew-dash.lovable.app

## What is this?
Sales analytics dashboard for Bright Coffee (Jan-Jun 2023) analyzing 3 NYC locations, $698K revenue, 149K transactions.

## Design Process
- **Miro** - Brainstorming user flow, KPI structure, wireframe planning
- **Canva** - Dashboard layout mockups, color palette (#6F4E37 coffee brown), presentation slides

## Tools Used
- **Google Sheets** - Data cleaning & validation
- **Databricks** - SQL processing, aggregations by store & product_type
- **Power BI** - Initial KPI cards and revenue logic
- **Data Studio** - Monthly trend charts
- **Lovable** - Final interactive dashboard build & hosting

## Key Findings
- Top Category: Barista Espresso $91,406 (13.1%)
- Top Product: Sustainably Grown Organic Lg Hot chocolate $21,152
- Peak: Morning 70K transactions, Monday best day $101,677
- Growth: $80K (Jan) to $175K (Jun) = 118% growth

## Recommendation
Morning staffing increase, push Lg Hot chocolate + Latte Rg, bundle Bakery (10.8% share) to lift $3.66 avg unit.
